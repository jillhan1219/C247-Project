● The metrics are all character-level error rates, expressed as percentages,
  computed using Levenshtein edit distance between the predicted text and the
  ground truth target text.

  ---
  Metrics Explained

  All four metrics share the same denominator: the total number of characters in
   the target (ground truth) sequence.

  Metric: CER (Character Error Rate)
  Formula: (insertions + deletions + substitutions) / target_len × 100
  Meaning: Total edit distance as a % of target length. The primary metric.
  ────────────────────────────────────────
  Metric: IER (Insertion Error Rate)
  Formula: insertions / target_len × 100
  Meaning: % of extra characters the model hallucinated that weren't in the
    target.
  ────────────────────────────────────────
  Metric: DER (Deletion Error Rate)
  Formula: deletions / target_len × 100
  Meaning: % of target characters the model missed entirely.
  ────────────────────────────────────────
  Metric: SER (Substitution Error Rate)
  Formula: substitutions / target_len × 100
  Meaning: % of target characters the model predicted as the wrong character.

  Note: IER + DER + SER = CER by construction.

  ---
  Results from Your Run

  Validation:
  - CER: 21.75% = IER (5.78%) + DER (1.42%) + SER (14.55%)
  - The dominant error type is substitution — the model decoded the wrong
  character but didn't skip or add characters wholesale.

  Test:
  - CER: 23.67% = IER (5.73%) + DER (1.69%) + SER (16.25%)
  - Slightly worse than validation, which is expected. Substitution errors again
   dominate.

  The CER is the monitor_metric (minimized during training), so it's the key
  number to optimize. Lower is better.
